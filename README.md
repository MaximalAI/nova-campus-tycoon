# Nova Campus Tycoon

A day-based café management game on a university campus: buy ingredients, set prices, serve students, upgrade your shop and buy out the competitor until you hold the monopoly.

## Run
```bash
uv sync
uv run streamlit run app.py
```

## Test
```bash
uv run pytest
```
